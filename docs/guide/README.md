# Academic Project Guidelines (`docs/guide`)

Contains the official departmental senior design project guidelines and timeline requirements.

## Files

- `SDPGuide_Fall2025 (1).pdf`: University of Sharjah College of Computing and Informatics Senior Design Project Handbook. Details grading rubrics, project phases (SDP 1 and SDP 2), milestone deadlines, presentation requirements, and committee evaluation standards.
- `Tutorial_SPD_PROJECT.pdf`: Tutorial slides and instructions for Senior Design Project students detailing milestone workflows, report structuring, and advisor interaction guidelines.

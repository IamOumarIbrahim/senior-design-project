# Project Documentation (`docs`)

This directory contains research papers, guidelines, templates, system specifications, compiled reports, and Overleaf LaTeX proposals for the Senior Design Project.

## Subdirectories and Contents

| Directory | Purpose |
| :--- | :--- |
| `guide/` | Official academic course guide and milestone instructions from the University of Sharjah. |
| `PDFs/` | Compiled final PDF deliverables (including the compiled `Proposal.pdf`). |
| `references/` | Literature review references, academic papers on driver monitoring, and benchmark manuscripts. |
| `report/` | Full LaTeX proposal and report source code, including TikZ accident charts, empirical study figures, acronyms, and bibtex citations. |
| `templates/` | Official Word templates for the Literature Review and Senior Design Project (SDP 1 / SDP 2) reports. |

## Key Specifications

- `VigilBench_Spec.md`: Complete autonomous execution specification detailing the 8-module pipeline, data protocol, ethics controls, baseline models, GRU challenger, and gate verification criteria.

# Acronym Definitions (`docs/report/Proposal/acronyms`)

Contains indexed glossaries and acronym entries for the LaTeX proposal.

## Files

- `acronyms.tex`: Defines all project acronyms using `\newacronym`, including:
  - `\gls{dms}`: Driver Monitoring System
  - `\gls{ir}`: Infrared
  - `\gls{rgb}`: Red-Green-Blue
  - `\gls{yolo}`: You Only Look Once
  - `\gls{gsr}`: General Safety Regulation (EU 2024 mandate)
  - `\gls{ear}`: Eye Aspect Ratio
  - `\gls{perclos}`: Percentage of Eye Closure
  - `\gls{ema}`: Exponential Moving Average
  - `\gls{wal}`: Write-Ahead Logging
  - `\gls{roi}`: Region of Interest
  - `\gls{rta}`: Roads and Transport Authority (Dubai)

# Proposal LaTeX Source (`docs/report/Proposal`)

Main proposal document for *"Design and Implementation of an Edge-Based Driver Monitoring System with False Alarm Reduction"*.

## Files and Directories

| Item | Type | Description |
| :--- | :--- | :--- |
| `Proposal.tex` | Master File | Main LaTeX document declaring packages, title page, table of contents, lists of figures/tables, and chapter inputs. |
| `Proposal.pdf` | Document | Compiled 19-page proposal deliverable. |
| `acronyms/` | Directory | Acronym definitions for DMS, YOLO, GSR, EAR, PERCLOS, WAL, etc. |
| `Bibliography/` | Directory | BibTeX references (`references.bib`) cited across all chapters. |
| `Chapters/` | Directory | Individual chapter files (`Chapter_1.tex` through `Chapter_5.tex`). |
| `Figures/` | Directory | Rendered TikZ graphics, empirical study charts, and institutional logos. |

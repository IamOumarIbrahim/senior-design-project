# Proposal Chapters (`docs/report/Proposal/Chapters`)

Contains the modular LaTeX chapters for the Senior Design Project proposal.

## Files

| Chapter | Title | Focus |
| :--- | :--- | :--- |
| `Chapter_1.tex` | Introduction & Overview | Problem statement, TikZ accident statistics, UAE distraction survey, key differentiators, empirical study subfigures, Required/Desired/Future feature specification tables, project roadmap, and report organization. |
| `Chapter_2.tex` | Literature Review | Evolution of in-cabin monitoring, limitations of single-frame computer vision, and gap analysis for user-friendly adaptive systems. |
| `Chapter_3.tex` | Technical Background | Embedded edge hardware, Raspberry Pi 5 architecture, camera sensor optics, object detection principles, and temporal metrics (EAR, PERCLOS). |
| `Chapter_4.tex` | Proposed Solution | Complete edge-cloud architecture, dynamic ROI cropping, temporal EMA filter, power-cut-safe SQLite logging, and desktop analytics dashboard. |
| `Chapter_5.tex` | Research Methodology | Empirical validation protocols, subject-disjoint dataset collection, hard-negative mining, and hardware benchmarking. |
